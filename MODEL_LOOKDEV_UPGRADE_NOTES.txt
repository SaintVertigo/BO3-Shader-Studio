BO3 HLSL Previewer - Material Lookdev + Custom Model Upgrade
============================================================

Baseline:
- BO3_HLSL_Previewer_GLSL_Converter_Overhaul_Source
- Includes all prior APE/material, sphere, fullbright, background, install-history,
  target-selection, and converter-overhaul fixes.

New viewport features
---------------------
- GGX-style direct specular in deferred Final Lit preview.
- Environment reflection contribution when an environment is loaded and enabled.
- Exposure EV control (-6..+6).
- Tone maps: Linear, Reinhard, ACES fitted.
- Lighting presets: Studio, Daylight, Overcast, Dark Interior, Fullbright.
- Procedural lookdev ground/checker plane in the deferred final compositor.
- Adjustable contact-shadow aid beneath centered preview geometry.
- Wireframe rasterizer mode.
- Existing GBuffer debug views remain available for normal/spec/gloss/AO/emissive inspection.

Custom model import
-------------------
- OBJ: native parser, polygon fan triangulation, positive/negative indices,
  UVs/normals, generated normals if absent, generated tangents.
- FBX: built-in ASCII FBX mesh-array parser (Vertices, PolygonVertexIndex,
  UV/UVIndex, Normals). Binary FBX is detected and rejected with a clear message.
- XMODEL: text XMODEL_EXPORT/XMODEL parser using global VERT/OFFSET positions and
  TRI face blocks with NORMAL/UV data. Compiled/proprietary BO3 xmodel assets are
  rejected rather than interpreted unsafely.
- Imported models are centered and normalized to a predictable lookdev scale.
- 2 million vertex safety cap.
- Import button in the preview toolbar and Scene / Lighting panel.
- Drag-and-drop OBJ/FBX/XMODEL_EXPORT onto the application.
- Custom Model becomes the fifth preview-mesh option.

Parity rule
-----------
The upgraded lighting/ground/tone mapping are viewport lookdev aids only.
The BO3 target shader and package adapter are unchanged by these controls, so
shader/package validation remains separate from presentation lighting.
