# BO3 Shader Studio

BO3 Shader Studio is a Windows shader creation, preview, conversion, and export tool built specifically for Call of Duty: Black Ops III. It includes shader editing and conversion, real-time material/model/sky previews, beginner-friendly effect tools, and BO3-ready export workflows.

## Download

1. Open the [Releases](https://github.com/SaintVertigo/BO3-Shader-Studio/releases) page.
2. Download the latest `BO3_Shader_Studio.zip` release file.
3. Extract the ZIP to a folder on your PC.
4. Run `BO3HLSLPreviewer.exe`.

Do not run Shader Studio directly from inside the ZIP.
